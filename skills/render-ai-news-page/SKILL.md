# AI 新闻单页面生成

## 行为覆写

- 必须先按意图表选择唯一透镜并完整读取；在此之前不得调用生成工具或修改模板。
- 新闻内容必须由用户独立提供。本 skill 不搜索、补充或核实新闻。
- 普通生成不得修改模板、lint 规则或 CLI。
- 涉及模板或规则修改时，以开发维护透镜为唯一入口；该透镜包含修改后的生成回归。

## 边界

本 skill 只处理一条业务链：完整新闻文本整理为保真 Markdown 中间稿，经唯一基准模板生成单页面 HTML，并通过 lint 后交付。不得为缩短页面而总结、删减、重排或改写新闻正文。

## 意图识别

**先通读全表，再选分支。**

| 意图信号 | 分支 | 文件 |
|----------|------|------|
| 用文件、当前消息或 Agent 上下文中已提供的新闻稿生成、重建或校验单页面 HTML | 普通生成 | [flows/generate.md](flows/generate.md) |
| 开发者明确要求微调模板、修改 lint、维护 Go CLI 或执行开发验收 | 开发维护 | [flows/maintain.md](flows/maintain.md) |

选定透镜后，回复一句“走 X，依据：用户提到 <原话片段>；下一步读取 <文件>”，然后读取对应文件并按其流程执行；在此之前不得读取工具源码或调用命令。

两行都不匹配时停止并请用户说明目标，不得扩展为新闻搜集、多模板、PDF、图片导出或发布流程。
